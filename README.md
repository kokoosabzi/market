# Market

نرم‌افزار فروشگاهی دسکتاپ، محلی و فارسی برای ویندوز؛ با پایگاه داده SQLite و قابلیت کار بدون اینترنت.

> وضعیت پروژه: مرحلهٔ مستندسازی و تثبیت طراحی. هنوز پیاده‌سازی اجرایی آغاز نشده است.

## محدودهٔ نسخهٔ اول
- مدیریت کالاها و دسته‌بندی‌ها
- ثبت فاکتور خرید و فروش
- گردش موجودی، برگشت‌ها و اصلاحات قابل پیگیری
- محاسبهٔ بهای تمام‌شده با میانگین موزون متحرک
- گزارش‌های فروش، خرید، موجودی و سود با نمایش شفاف هزینه‌های تخمینی
- خروجی Excel/CSV و PDF
- تنظیمات مالیات و عوارض، پشتیبان‌گیری و بازیابی

نسخهٔ اول دفتر حساب مشتری و تأمین‌کننده، دریافت و پرداخت، صندوق، تسویه و اتصال بانکی ندارد. اسناد فقط اطلاعات لازم برای ثبت فاکتور را نگه می‌دارند.

## اصول قطعی
- مبالغ در پایگاه داده به ریال و به‌صورت عدد صحیح ذخیره می‌شوند؛ نوع REAL برای پول ممنوع است.
- نمایش تومان صرفاً در رابط کاربری است.
- فروش بیش از موجودی مجاز است، همراه با هشدار.
- در فروش از موجودی منفی، آخرین بهای خرید معتبر می‌تواند به‌عنوان بهای تخمینی استفاده شود. اگر سابقهٔ معتبر موجود نیست، بهای تمام‌شده نامشخص می‌ماند.
- بهای ثبت‌شدهٔ هر قلم فروش و وضعیت تخمینی آن حفظ می‌شود؛ اسناد نهایی بی‌صدا بازنویسی نمی‌شوند.
- نهایی‌سازی سند و تغییرات موجودی باید اتمی باشند.
- رابط کاربری فارسی/RTL و دارای انتخاب‌گر تاریخ شمسی خواهد بود.

## معماری پیشنهادی
Electron برای دسکتاپ، HTML/CSS/JavaScript برای رابط کاربری و SQLite برای داده‌های محلی. دسترسی به سیستم‌عامل و پایگاه داده باید محدود و اعتبارسنجی‌شده باشد. پایگاه داده خارج از پوشهٔ نصب نگهداری می‌شود.
