# Market

نرم‌افزار فروشگاهی دسکتاپ، محلی و فارسی برای ویندوز؛ با Electron و SQLite، با هدف اجرای آفلاین.

## وضعیت
شاخهٔ `feature/complete-market-ui-catalog` زیرساخت نسخهٔ اول را ادامه می‌دهد و رابط برنامه و مدیریت کالا/دسته‌بندی را پیاده‌سازی می‌کند. این شاخه هنوز نسخهٔ کامل فروشگاهی نیست؛ خرید، فروش، برگشت، گزارش و پشتیبان‌گیری مراحل بعدی‌اند.

## امکانات فعلی شاخه
- رابط فارسی/RTL با پوستهٔ روشن، تیره و خودکار سیستم.
- مدیریت کالا: کد یکتا، نام، دسته‌بندی، واحد، قیمت خرید/فروش به ریال، حداقل موجودی و توضیحات.
- جست‌وجو بر اساس کد، نام و دسته‌بندی؛ غیرفعال‌سازی به‌جای حذف فیزیکی.
- دسته‌بندی‌های یکتا.
- تنظیم نمایش قیمت به ریال یا تومان؛ دادهٔ پایگاه همواره INTEGER ریال است.
- ذخیرهٔ محلی SQLite در مسیر دادهٔ کاربر؛ نسخهٔ بسته‌بندی‌شده برای کاربر نهایی به Node.js نیاز ندارد.

## محدودهٔ خارج از این شاخه
فاکتور خرید/فروش، گردش موجودی، برگشت و ابطال، گزارش‌ها و خروجی‌ها، پشتیبان‌گیری/بازیابی و انتشار نهایی هنوز نیاز به پیاده‌سازی و آزمون دارند. برنامه فعلاً دفتر دریافت/پرداخت یا بانک ندارد.

## توسعه و آزمون
پیش‌نیاز توسعه: Node.js نسخهٔ 22 و npm.

```bash
npm ci
npm test
npm start
```

ساخت نصب‌کننده روی Windows:
```bash
npm run dist:win
```

جزئیات طراحی و قواعد در `docs/BUSINESS_RULES.md`، `docs/ARCHITECTURE.md` و `docs/ROADMAP.md` هستند. نتیجهٔ آزمون اجرا‌نشده نباید موفق گزارش شود.
