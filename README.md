# Market

نرم‌افزار فروشگاهی دسکتاپ، محلی و فارسی برای Windows با Electron و SQLite.

## وضعیت این شاخه
شاخهٔ `feature/complete-market-ui-catalog` یک نسخهٔ آزمایشی یکپارچه از زیرساخت، مدیریت کالا، اسناد خرید و فروش، گردش موجودی، برگشت‌های متصل به سند، گزارش CSV/PDF و پشتیبان‌گیری/بازیابی ارائه می‌کند. پیش از استفادهٔ واقعی باید آزمون‌های CI، بازبینی کد و نصب/اجرای دستی روی رایانهٔ مقصد را کامل کرد. این نسخه را هنوز انتشار تولیدیِ نهایی تلقی نکنید.

## امکانات پیاده‌سازی‌شده در این شاخه
- رابط فارسی/RTL واکنش‌گرا با پوستهٔ روشن، تیره و خودکار سیستم.
- مدیریت کالا و دسته‌بندی، جست‌وجو، اعتبارسنجی کد یکتا و غیرفعال‌سازی به‌جای حذف فیزیکی کالا.
- ثبت پیش‌نویس و نهایی‌سازی خرید/فروش با اقلام؛ اسناد پیش‌نویس موجودی را تغییر نمی‌دهند.
- موجودی بر پایهٔ گردش‌های ثبت‌شده؛ فروش بیش از موجودی مجاز است و با هشدار مشخص می‌شود.
- آخرین قیمت خرید معتبر برای ارزش‌گذاری جاری و snapshot بهای تمام‌شدهٔ قلم فروش؛ بدون میانگین موزون.
- برگشت خرید/فروش متصل به سند و قلم اصلی با کنترل مقدار تجمعی.
- گزارش‌های موجودی، خرید، فروش و برگشت با خروجی CSV و PDF؛ CSV در Excel قابل بازکردن است.
- پشتیبان‌گیری SQLite با اعتبارسنجی و بازیابی با ایجاد نسخهٔ ایمنی پیش از جایگزینی.
- ذخیرهٔ مبالغ به‌صورت INTEGER ریال؛ نمایش ریال/تومان صرفاً در رابط کاربری.
- داده در مسیر `app.getPath('userData')/data/market.sqlite` و بیرون از پوشهٔ نصب نگهداری می‌شود.

## محدودیت‌های شناخته‌شدهٔ پیش از انتشار
- انتخاب‌گر تاریخ سیستم عامل، تاریخ میلادی را برای ورود نگه می‌دارد و پیش‌نمایش شمسی ارائه می‌کند؛ انتخاب‌گر کاملاً شمسی و گزارش‌های بازه‌تاریخی هنوز نیازمند تکمیل‌اند.
- اصلاح/ابطال برگشت قطعی، ممیزی جامع رخدادها، آزمون‌های یکپارچگی سناریوهای مالی و آزمون واقعی بازیابی هنوز باید بازبینی/تکمیل شوند.
- آزمون خودکار نصب‌کننده جایگزین نصب و ارتقای دستی روی رایانهٔ مقصد نیست.
- دفتر حساب اشخاص، دریافت/پرداخت، صندوق، تسویه و اتصال بانکی در محدودهٔ برنامه نیستند.

## توسعه
پیش‌نیاز: Node.js نسخهٔ 22 و npm روی رایانهٔ توسعه‌دهنده.

```bash
npm ci
npm test
npm start
```

ساخت نصب‌کنندهٔ Windows (روی Windows):
```bash
npm run dist:win
```

کاربر نهایی برای اجرای نسخهٔ بسته‌بندی‌شده نیاز به نصب جداگانهٔ Node.js ندارد. برای وضعیت واقعی مراحل به `PROGRESS.md` و `docs/ROADMAP.md` مراجعه کنید.
